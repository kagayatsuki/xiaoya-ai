# WHUT AI 答题助手

一个用于 **武汉理工大学课程平台（whut.ai-augmented.com）** 的 Chrome 扩展（Manifest V3）。

它做三件事：把课程作业里的题目交给你自己配置的大模型作答、自动勾选客观题、并守护「自主观看」视频的播放。

> 自动填入 / 自动勾选不会提交，请自行核对后手动提交。

## 功能

- **主观题**：抓取页面题目（含 iframe / Shadow DOM），调用 OpenAI 兼容接口生成答案并填入输入框
- **客观题**：扫描单选、多选、判断题，AI 作答后自动勾选（支持原生控件、`role=radio/checkbox`、纯 div 选项）
- **自主观看任务**：一键扫描并批量打开任务链接
- **视频播放守护**：每 15 秒检查一次，视频暂停时点击播放区域；自动起播带冷却，不会反复切播放/暂停
- **倍速播放**：4x / 8x / 12x / 16x，劫持 `playbackRate` 防止播放器改回原速
- **完成打卡**：视频播完后每 30 秒自动点击「点我完成任务」
- **弹窗屏蔽**：自动隐藏账号安全提示弹窗（不会替你点击账号操作）
- **日志**：弹窗内「查看原始日志」同时展示页面控制台与插件操作日志，包含 AI 原始回复、点击落点等

## 安装

1. 克隆或下载本仓库
2. 打开 `chrome://extensions`
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本仓库目录
5. 刷新已打开的课程平台页面

## 配置

点击扩展图标 → **⚙️ API 设置**：

| 字段 | 说明 |
| --- | --- |
| API 地址 | 任意 OpenAI 兼容的 `/chat/completions` 地址，例如 `https://api.openai.com/v1/chat/completions`、`https://api.deepseek.com` |
| API Key | 你的密钥，例如 `sk-...` |
| 模型 | 例如 `gpt-4o-mini`、`deepseek-chat` |
| 系统提示词 | 主观题的作答风格，可按需修改 |

配置保存在浏览器的 `chrome.storage.local` 中，仅本机可读。

## 使用

### 主观题

1. 打开作业页，点击「📋 抓取题目」
2. 勾选要作答的题目，点击「🚀 生成并填入」
3. 核对内容后手动提交

### 客观题

1. 打开测验页，点击「🎯 扫描客观题」
2. 勾选题目，点击「🤖 AI 作答并勾选」
3. 核对选项后手动提交

### 视频

- 打开课程视频页即可，扩展会自动起播；之后每 15 秒检查，若暂停会自动点击播放区域
- 在弹窗拖动「视频倍速」即时生效
- 视频播完后扩展每 30 秒点击一次「点我完成任务」

## 隐私说明

- 本项目**不包含任何 API Key**，所有密钥由使用者自行填写并只保存在本地
- 扩展不收集、不上报任何数据
- 题目文本会发送到**你自己配置的 API 服务**用于生成答案
- 登录由你本人完成，扩展不会读取或保存账号密码；检测登录态时只读取平台自身的 `access-token` Cookie
- 页面日志只保存在内存中，供弹窗排错使用，不会外传

## 目录结构

```
manifest.json      扩展清单（MV3）
background.js      后台：AI 请求、跨标签页注入、完成打卡轮询
content.js         页面脚本：题目抓取/填入、客观题、视频播放与倍速
content.css        页面内提示样式
security-popup.js  账号安全弹窗屏蔽
popup.html/js/css  扩展弹窗界面与日志
icons              扩展图标
```
